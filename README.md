# budget-pir — расчёт бюджета инженерных изысканий

[![Тесты](https://github.com/vaprol4gpt/budget-pir/actions/workflows/tests.yml/badge.svg)](https://github.com/vaprol4gpt/budget-pir/actions/workflows/tests.yml)

## Что это

Программа расчёта бюджета **проектно-изыскательских работ (ПИР)** по разделам инженерных
изысканий. Выпускная квалификационная работа (ВКР). Для кого: сметчик или руководитель проекта в
проектно-изыскательской компании, который сейчас считает бюджет изысканий вручную в Excel, и
рецензент работы.

Программа ведёт оператора по шагам:

1. **Объект и ТЗ** — данные объекта и параметры технического задания (ТЗ);
2. **Ведомость объёмов** — что и сколько делать (скважины, метры бурения, гектары съёмки…);
   часть строк программа предлагает сама по известным связям; ведомость можно загрузить из Excel;
3. **Максимальный бюджет (смета)** — цена по сборникам базовых цен (СБЦ — государственные
   справочники расценок на изыскания) с пересчётом в текущие цены (индекс) и НДС;
4. **Минимальный бюджет** — себестоимость ресурсным методом (макет, см. «Ограничения»);
5. **Сводный бюджет** объекта по всем разделам, снижение цены, лист коммерческого предложения,
   выгрузка в Excel.

Разделов изысканий пять: инженерно-геологические (ИГИ), инженерно-геофизические (ИГФИ),
инженерно-геодезические (ИГДИ), инженерно-экологические (ИЭИ), инженерно-гидрометеорологические
(ИГМИ).

## Модель расчёта — коротко

Строка сметы — «объём × базовая цена × произведение коэффициентов» (вид A) или «ставка × сумма
других строк» (виды B, C — начисления: внешний транспорт, организация и ликвидация работ, районный
коэффициент и т.п.; защита от циклов). Базовые цены берутся из справочника `data/references.sqlite`,
который собирается из эталонных смет `reference_data/`. Сумма раздела пересчитывается в текущие
цены индексом на дату расчёта и облагается НДС по ставке на ту же дату (20 % по 31.12.2025, 22 % с
01.01.2026). Сводный бюджет складывает только подтверждённые разделы; снижение цены — на уровне
раздела и сводной, НДС — от суммы после снижения.

Каждый раздел проходит два этапа: **ведомость объёмов** (подтверждается неизменяемым снимком) и
**смета** (параметры расчёта, правки оператора с журналом изменений, «своя строка» для работ вне
сборника — с обязательным основанием). Минимум считается от объёмов ведомости: объём / норма
выработки → люди × оклады × месяцы → прямые затраты, накладные, налоги, резерв; коэффициент
допустимого снижения = минимум / максимум без НДС.

## Ограничения (важно)

- **Индексы пересчёта цен — только на III квартал 2026 г.** На более позднюю дату программа берёт
  последний известный индекс и предупреждает (строгий режим — итога нет). Новые индексы вносятся в
  `data/indeksy.json`.
- **Минимальный бюджет — макет, не калиброван**: нормы выработки — допущения с указанным
  источником, ставок себестоимости в репозитории нет (шаблон — `data/norms/norms_firm.example.json`).
  Коэффициент снижения из него как ориентир цены не использовать.
- **Эталонная проверка показывает повторение арифметики готовой сметы** (± 0,1 %) при
  параметрах, взятых из той же сметы. Выбор параметров для нового объекта без готовой сметы
  программа не делает — его вводит оператор.
- Архив фактической себестоимости в репозитории — **демонстрационный** (условные объекты,
  выдуманные числа).

## Установка

Нужны **Windows 10/11**, **Python 3.13** (с python.org, вместе с лаунчером `py`) и **Git**.

```bat
git clone https://github.com/vaprol4gpt/budget-pir.git C:\PROJECTS\budget-pir
cd C:\PROJECTS\budget-pir
setup.bat
```

Путь к папке — короткий (до ~120 символов: ограничение Windows на длину пути внутри окружения).

`setup.bat` создаёт виртуальное окружение `.venv`, ставит точные версии библиотек из
`requirements-lock.txt` и сам проект (`pip install -e .`), собирает справочник расценок
`data/references.sqlite` из `reference_data/` и запускает тесты; в конце пишет «ГОТОВО».

Без `setup.bat` (любая ОС с Python 3.13):

```bash
python -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
.venv/bin/python -m pip install --no-deps -e .
.venv/bin/python data/build_references.py
```

## Запуск

| Что | Как |
|---|---|
| Программа в браузере | `launch_app.bat` (окно консоли — это сервер программы) или `python -m streamlit run app/streamlit_app.py` из корня |
| Тесты | `.venv\Scripts\python.exe -m pytest -q` |
| Сквозной расчёт текстом | `.venv\Scripts\python.exe run_budget_stub.py --date 2026-09-30` — пять разделов на учебных объёмах и сводный бюджет; контрольный итог **28 680 880,97 руб.** с НДС 22 % |
| Программа одним файлом | `build_release.bat` — `BudgetPIR.exe` (PyInstaller) в папку `releases/` |

Часть тестов пропускается с объяснением причины: им нужны данные, которых в публичной копии нет
(внутренние ставки, настоящий архив себестоимости).

## Структура

```
core/              общее для всех разделов: расчёт строки сметы, справочник, индексы и НДС, правки
                   оператора, этапы, сохранение смет, начисления, себестоимость, сводный бюджет, Excel
modules/<раздел>/  особенности раздела (geology, geophysics, geodesy, ecology, hydromet):
                   module.py — смета, cost.py — себестоимость, key_volumes.py — ключевые объёмы
app/               интерфейс Streamlit: streamlit_app.py (главный), ui*.py (экраны), app_pages/ (меню),
                   theme/ (оформление из docs/design/)
data/              build_references.py (сборка справочника), norms/ (нормы себестоимости — допущения
                   с источником), pravila_parametrov.json (правила параметров), indeksy.json (индексы)
reference_data/    эталонные сметы двух объектов («Автодорога», «Карьер»; обезличены) и
                   демонстрационный архив себестоимости
tests/             автоматические тесты (pytest), в т.ч. сверка с эталонами
tools/             импорт ставок себестоимости, генераторы шаблонов Excel
docs/              техническая справка (ниже)
```

Принцип: всё общее — в `core/`, особенности вида работ — только в `modules/<раздел>/`.

## Документация

- `docs/rukovodstvo/Руководство_оператора.docx` — руководство оператора по шагам, со скриншотами
  (`docs/rukovodstvo/img/`); в программе — справка «Как работать с этим шагом» на каждой странице;
- `docs/multistage_design.md` — этапы «ведомость → смета», снимки, правки;
- `docs/etalon.md`, `docs/proverka_karer.md`, `docs/proverka_vedomosti.md` — эталонные сметы и как
  программа с ними сверяется;
- `docs/nachisleniya.md` — начисления (районный коэффициент, транспорт, организация работ) с
  нормативными источниками;
- `docs/minimum_po_razdelam.md` — минимальный бюджет по разделам;
- `docs/predmetnaya_oblast.md` — предметная область;
- `docs/hydromet_diagnostics.md` — разбор гидрометеорологии;
- `docs/generator_vedomosti.md` — ведомость из параметров ТЗ и ключевых объёмов;
- `docs/ui_guide.md` — правила экранов; `docs/design/` — токены оформления;
- `docs/known_risks.md` — известные риски;
- `docs/templates/` — шаблоны Excel (ведомости разделов, ставки себестоимости).
