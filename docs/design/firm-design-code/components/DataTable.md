# DataTable

Таблица сметы или ведомости: метки колонок прописными, суммы справа моноширинными цифрами, промежуточные и итоговая строки выделены.

- Классы: `vs-table`; числовые ячейки — `is-num`; промежуточный итог — `tr.is-sub`; итог — `tr.is-total` (заливка `accent-soft`, линия `accent`).
- Шифр расценки — `vs-code`. Единицы — в заголовке колонки, а не в каждой ячейке.
- Формат сумм: 1 234 567,89.
