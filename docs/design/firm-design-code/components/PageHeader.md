# PageHeader

Шапка шага на фирменном градиенте: номер шага со срезом, название, одна строка «что здесь делать», объект и статус.

- Классы: `vs-header vs-gradient--deep` (глубокий градиент, чтобы мелкий текст читался белым) → `vs-header__step` (`vs-slash` + «Шаг 3 из 5») → `vs-header__title` → `vs-header__lead` → `vs-header__meta`.
- Одна на страницу, в самом верху. Других градиентных блоков на экране программы нет.
- В строке `meta` — объект, дата расчёта, статус шага. Статус — бейдж (`StatusBadge`).
- Даёт потребитель: номер и название шага, пояснение, метаданные объекта.
