# Field

Поле ввода числа или текста с подписью, единицей измерения справа и строкой пояснения или источника.

- Классы: `vs-field` → `vs-field__label` → `vs-field__control` (input + `vs-field__unit`) → `vs-field__hint`. Ошибка — `is-error` на `vs-field`, текст ошибки в `vs-field__hint`.
- Рамка `border-strong` (3,5:1 к фону), фокус — кольцо `focus`.
- Под нормой или ставкой в `hint` пишется источник: «СБЦ-99, табл. 2, п. 4» или «ДОПУЩЕНИЕ (v5.2)».
- Числа — `tabular-nums`, единица — справа внутри поля.
