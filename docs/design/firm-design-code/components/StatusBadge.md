# StatusBadge

Короткая метка статуса шага или строки — всегда со словом или значком, не только цветом.

- Классы: `vs-badge` + `--done` (✓ готово), `--warn` (! предупреждения, допущения), `--error` (× ошибка), `--todo` (не начат), `--brand` (нейтральная изумрудная метка: «основной», «эталон»).
- Радиус `radius-xs`, без таблеток.
