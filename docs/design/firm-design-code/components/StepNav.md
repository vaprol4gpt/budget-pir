# StepNav

Левое меню программы: шаги процесса 1–5 отдельными строками, черта, служебные пункты; активный шаг залит, у каждого — статус.

- Порядок фиксированный и повторяет процесс компании: 1 Объект и ТЗ → 2 Ведомость объёмов → 3 Максимальный бюджет → 4 Минимальный бюджет → 5 Сводный бюджет. Затем `vs-nav__sep` и «Служебное»: Справочники, Версии.
- Каждый шаг — отдельная строка верхнего уровня, без вложенных групп и раскрывашек.
- Активный — `aria-current="page"`: мягкая изумрудная заливка, номер в квадрате `accent`.
- Справа у шага — бейдж статуса (`vs-badge`) или ничего.
- Вверху — изумрудная надпись «компания» (в тёмной теме — белая).
