# Figures

Ряд итоговых цифр: максимум, минимум, коэффициент; ключевая цифра выделена изумрудом.

- Классы: `vs-figures` (сетка) → `vs-figure` → `vs-label` + `vs-figure__value` (стиль `figure`, моноширинные цифры) + `vs-figure__unit` + `vs-figure__note`.
- Не больше трёх-четырёх цифр в ряд. Ключевая — одна, класс `vs-figure--key`.
- Под цифрой — что в неё входит или откуда она («с НДС 22 %», «по себестоимости»).
