# Callout

Сообщение над блоком: информация, предупреждение, ошибка, успех — значок, жирная первая строка, пояснение.

- Классы: `vs-callout` + `--info` / `--warn` / `--error` / `--done`; внутри `vs-callout__icon` (i, !, ×, ✓) и текст с `<b>` в первой строке.
- Ставится над блоком, к которому относится, не внизу страницы. Текст — на `ink`, цвет несёт только рамка и значок.
- Ошибка объясняет, что сделать: «Задайте район на шаге 1».
