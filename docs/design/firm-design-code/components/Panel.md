# Panel

Панель — белая карточка с рамкой для группы полей или результата: заголовок, пояснение, содержимое.

- Классы: `vs-panel` → `vs-panel__head` (`vs-panel__title` + пояснение `vs-panel__hint`, справа — бейдж или ссылка) → содержимое.
- Рамка `border`, фон `surface-raised`, радиус `radius-md`, без тени. Внутри не больше одного уровня вложенных рамок.
- Даёт потребитель: заголовок, пояснение, содержимое.
