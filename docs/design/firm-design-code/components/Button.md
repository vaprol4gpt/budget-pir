# Button

Кнопка действия: основная, второстепенная, текстовая, опасная.

- Классы: `vs-btn` + вариант `vs-btn--primary` / `--secondary` / `--ghost` / `--danger`; размер `--lg` (главное действие шага) или `--sm` (в таблицах).
- **Основная — одна на экран**, и только в панели «Действие» (`ActionPanel`). Заливка `accent`, текст `on-accent`.
- Второстепенные действия (экспорт, сохранить черновик, сбросить правки) — `--secondary` или `--ghost`.
- Необратимое (удалить версию, сбросить все правки) — `--danger` и всегда с подтверждением.
- Недоступная кнопка — атрибут `disabled` или `aria-disabled="true"`, причина пишется рядом текстом, а не только в подсказке.
- Подпись — глагол действия: «Утвердить смету», «Выгрузить в Excel». Не «ОК», не «Далее».
- Даёт потребитель: текст подписи, обработчик, состояние доступности.
