# ActionPanel

Панель «Действие» внизу шага: одно главное действие с пояснением, причина недоступности, второстепенные кнопки под чертой.

- Разметка: `vs-action` → `vs-action__kicker` (метка «ДЕЙСТВИЕ») → `vs-action__text` (что произойдёт) + основная кнопка `vs-btn--primary vs-btn--lg` → `vs-action__reason` (почему недоступно, если недоступно) → `vs-action__more` (второстепенные кнопки).
- Верхняя изумрудная линия — признак того, что здесь главное. На странице одна такая панель.
- Пояснение — одно предложение о последствии: «Смета зафиксируется и попадёт в сводный бюджет».
- Даёт потребитель: подпись кнопки, пояснение, причину блокировки, список второстепенных действий.
