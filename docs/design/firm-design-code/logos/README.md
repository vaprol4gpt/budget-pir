# Logos

Эмблема и надпись «компания» из фирменной презентации, форма без изменений, перекрашены в три цвета (PNG с прозрачностью; через `<img>` цвет не наследуется — бери файл нужного цвета).

- `firm-emblem-white.png`, `firm-wordmark-white.png` — белые, для градиента и `steel-950`.
- `firm-emblem-emerald.png`, `firm-wordmark-emerald.png` — изумруд `emerald-700`, для `surface` светлой темы.
- `firm-emblem-steel.png`, `firm-wordmark-steel.png` — чёрная сталь `#0E1413` (`ink` светлой темы), для документов и печати.
- `firm-band-white.png` — белая полоса с двойным срезом, только внизу слайда на градиенте.

Свободное поле — не меньше высоты буквы «В» надписи. Векторного логотипа в исходниках нет: для печати крупнее 10 см нужен вектор из брендбука.
